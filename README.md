# Data Analysis & AI/ML Website

A comprehensive and visually stunning website about **Data Analysis** and **Artificial Intelligence / Machine Learning**, built with HTML5 and CSS3, hosted on GitHub Pages.

This project was created as part of an internship task to demonstrate understanding of front-end web development, modern design aesthetics, and version control with Git.

## ✨ Features

- **Responsive Navigation Bar** — Fixed navbar with scroll effects, mobile hamburger menu, and active link highlighting
- **Hero Section** — Animated background orbs, statistics, and a stunning AI robot image
- **About AI/ML Section** — Cards covering AI, Machine Learning, and Deep Learning; real-world industry applications
- **Data Analysis Section** — 5-step analysis pipeline, interactive tool badges, and data visualization image
- **ML Algorithms Section** — 6 algorithm cards spanning supervised, unsupervised, and deep learning
- **Contact Section** — Functional contact form with validation, plus social links
- **Footer** — Full-featured with quick links, resources, and author info
- **Scroll Animations** — Elements fade in as you scroll using Intersection Observer API
- **Back-to-Top Button** — Appears on scroll, smooth transition
